# Who I am

Fill in the fields below. Anything still inside « » is treated as unset.

- Name: «your name»
- What I do: «e.g. I run a two-person studio building Shopify stores»
- What I sell, and for how much: «e.g. store builds £4k to £9k, monthly retainers £800»
- My clients: «two or three real examples»
- How I want to be spoken to: «e.g. short, dry, no preamble. Lead with the number or the name. Never say "Absolutely" or "Great question". If you don't know, say so in four words.»

Demo mode uses an invented studio (see data/generate_demo.py). It ignores nothing in this file, so change these fields to match you before you switch to real data.
